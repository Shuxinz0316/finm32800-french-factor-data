# Ken French three-factor monthly series

`build_factors.py` downloads the official Fama/French three-factor monthly CSV
archive, selects July 2025–June 2026, and converts percentage returns to decimals.
`french_factors.csv` is the resulting snapshot. The upstream file can be revised;
the committed snapshot and its Git hash identify the exact data used in the report.
Source: https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html

This is a local review copy. It has not been published to GitHub.
